# ✅ Lista de Tarefas

## 📌 Sobre
Sistema simples e prático para **anotar, organizar e gerir pequenas tarefas** do dia‑a‑dia.

### ⚙️ Funcionalidades
• Adicionar nova tarefa  
• Marcar como concluída  
• Remover ou atualizar itens

- HTML5
- CSS3
- JavaScript — lógica principal do funcionamento
