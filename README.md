📋 Gestor de Tarefas
 
Aplicação web simples, elegante e funcional para organizar suas atividades diárias, com armazenamento local no navegador.
 
🚀 Sobre o Projeto
 
Este é um gestor de tarefas desenvolvido com HTML, CSS e JavaScript puro, permitindo adicionar, editar, excluir, marcar como concluída, filtrar e pesquisar tarefas. Todos os dados são salvos no  localStorage , garantindo que suas tarefas permaneçam salvas mesmo após fechar o navegador.
 
O design utiliza a fonte Poppins e ícones do Font Awesome, com uma interface moderna, responsiva e animações suaves para melhor experiência do usuário.
 
 
 
✨ Funcionalidades
 
- ✅ Adicionar novas tarefas com data e hora automática
- ✅ Marcar/desmarcar tarefas como concluídas
- ✅ Editar o texto de qualquer tarefa
- ✅ Excluir tarefas
- ✅ Filtrar visualização: Todas | Pendentes | Concluídas
- ✅ Pesquisar tarefas por texto
- ✅ Armazenamento automático no  localStorage 
- ✅ Interface responsiva para celular e desktop
- ✅ Animações e efeitos visuais modernos
 
 
 
🛠️ Tecnologias Utilizadas
 
- HTML5: Estrutura semântica da página
- CSS3: Estilização avançada, flexbox, sombras e animações
- JavaScript: Lógica de manipulação do DOM e armazenamento
- LocalStorage: Persistência de dados no navegador
- Font Awesome: Ícones visuais
- Google Fonts: Fonte Poppins para tipografia limpa
